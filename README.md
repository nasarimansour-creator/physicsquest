# فیزیک‌کرفت — بازی آموزشی فیزیک دوازدهم تجربی

پروژهٔ اولیهٔ اپ اندروید با رابط فارسی و راست‌چین، بازی آفلاین، جان، سکه، XP، پنج مرحله، پاسخ‌سنجی و توضیح پاسخ.

## ساخت APK در Android Studio
1. Android Studio را نصب کنید.
2. از **Open** پوشهٔ `physicsquest` را باز کنید.
3. صبر کنید Gradle Sync کامل شود و SDK 35 نصب باشد.
4. از منوی **Build > Build APK(s)** فایل APK را بسازید.
5. خروجی معمولاً در `app/build/outputs/apk/debug/app-debug.apk` است.

## ساخت خودکار در GitHub Actions
پروژه را در یک مخزن GitHub بارگذاری کنید. workflow موجود در `.github/workflows/android.yml` با هر push یک APK آزمایشی می‌سازد؛ فایل از بخش Actions همان اجرای workflow قابل دریافت است.

این پروژه به‌صورت پیش‌فرض APK امضاشده برای انتشار در فروشگاه تولید نمی‌کند؛ خروجی debug برای نصب و آزمایش است.
